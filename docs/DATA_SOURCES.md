# 数据与资源来源

本公开仓库包含完整的查询、绘图、缓存与规划代码，但内置资料不等于现有发行版的全国资料覆盖。第三方接口能返回数据，也不表示本项目获得了该服务商的数据再许可。

## 随仓库提供的离线数据

`assets/metro_data.json` 是从四个 OpenStreetMap 轨道图层派生的真实基础拓扑，覆盖北京、上海、广佛及深圳。它不是虚构演示站点，也不是官方时刻表。线路在分岔和资料缺口处分段；分段只是图结构，不表示运营方存在相同的贯通交路。

- 北京：524 条具名 OSM 站点记录，499 段可证实的轨道区间。
- 广佛：449 条具名 OSM 站点记录，424 段可证实的轨道区间。
- 上海：531 条具名 OSM 站点记录，515 段可证实的轨道区间。
- 深圳：432 条具名 OSM 站点记录，416 段可证实的轨道区间。

目录共 96 个连续拓扑分段、1940 条站序记录、1848 个物理区间。站序记录含分岔边界的重复站，并非独立车站总数。没有以两站直线补出缺失的轨道，也没有随意补出运营时间。资料快照来自 2026-11-05 的构建输入，不保证反映此后所有开通、改名及运营调整。

### 坐标与原始节点证据

公开版重新从原始 OSM 轨道提取文件的具名 `station` / `stop` 等节点定位，再投影至同属 OSM 的线路成员轨道；没有采用高德坐标作为缺失站点的回退。无法找到具名 OSM 节点或轨道不连通的站和区间留空，不从其他来源混入。

`data/osm-station-provenance.json` 记录每一条保留站点的 OSM 节点 ID、坐标生成方式及各区域原始提取文件摘要；缺失项也逐项列出。`data/osm-source-validation.json` 给出汇总。轨道样本来自 OSM way 顶点及上述 OSM 节点在这些轨道上的投影点。

`data/rebuild_osm_catalog.py` 可由仓库内的地理图层重新生成目录，并验证每一个目录区间都确实存在于图层。`data/osm-catalogue-checks.json` 记录每条物理线路的连续性检查。部分线路颜色来自 OSM relation 的 `colour` 标签，见 `data/osm-line-metadata.json`；没有颜色标签时使用本项目自己的示意配色，并非宣称官方线路颜色。

## 不随公开仓库提供的资料

- 官方地铁、广东城际及上海市域铁原图、金山铁路时刻表图片。
- 对官方图进行精确描摹的矢量走线和布局资产。
- 从高德抓取的全国地铁快照、原始规整图、带专有来源坐标的数据库。
- 仅有来源网址而未核实再分发条款的运营方时刻表、港澳公交离线目录。
- 角色形象重绘图标及第三方设计参考文档副本。

清单及旧文件摘要见 `data/source-asset-audit.json`。这份清单用于解释排除项，不包含原文件内容。注明来源、在网页上能下载、个人非商用或重新描成矢量，都不应被写成自动获得再分发许可的证明。

公交在线查询所用服务与地铁数据许可分开。代码保留相应适配器，不对服务商接口的长期可用性、覆盖范围或使用许可作额外承诺。

`regional-rail-telecodes.tsv` 仅保留少量站名与车站代码的事实性对应，供本地构建区间查询参数；不包含班次时刻或地图。它不授予查询服务本身的使用权。

## 使用自行有权分发的数据

构建脚本支持 `APP_ASSETS_OVERLAY` 指向本机额外资产目录。该目录不提交到 Git；它用于开发者自行提供、且有权使用和分发的兼容资料，不是规避许可的机制。覆盖前请核对数据格式、坐标系、来源许可和有效日期。

仅使用公开数据构建时，不应把缺时刻表的拓扑当成完整运营时刻或真实列车位置。其他城市可以通过已有数据源按需查询，但能否查询取决于用户配置、服务可用性和相应许可。

## 图标和字体

公开版使用本项目新绘制的蓝色公交 Android Vector 图标（`res/drawable/ic_sayu.xml` 与 `ic_launcher.xml`），按主代码 MIT 许可发布。资源名为了兼容现有代码保留，不表示图标仍使用原角色形象。界面使用系统字体，仓库不附第三方字体二进制。
