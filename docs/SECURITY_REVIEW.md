# 公开源码准备审查

审查日期：2026-11-09。对象是独立的公开源码目录，不是开发工作区的全部文件，也不是对外部数据服务的授权证明。

## 配置与凭据

- 公开的 Java 源码未内置个人高德 Key；`ChelaileDataSource.GAODE_KEY` 保持空值。用户自行配置的 Key 只在运行时写入应用私有存储。
- 没有复制开发工作区的 `build/`、生产签名库、签名口令、服务器私钥、SSH 配置、官网采集工具中的认证值、Cookie 文件、原始接口响应、临时截图或用户首选项。
- 车来了和掌上公交的客户端实现按项目功能要求保留。用于协议请求的公共参数、签名和解密常量不等于维护者的个人凭据；保留它们也不代表取得了接口提供方的使用授权。
- 测试使用程序内构造的模型与公共站点案例，没有附带用户的 GPS 轨迹、设备导出的 SharedPreferences、位置历史或可复用会话 Cookie。公共站点名与坐标测试不应解释为用户行程记录。
- 下载域名和签名证书的公开指纹不是私钥。公开源码中保留用于校验的逻辑；正式发布签名仍需由维护者在仓库外保管。

## 自建版本与更新

默认构建包名为 `com.holi.prdbus.opensource`，不覆盖正式版；构建脚本同时调整安装包的文件提供者 authority，避免与正式版冲突。生成的 R 类和 Java 类保持原命名空间。

`PublicBuildConfig.OFFICIAL_UPDATES` 默认为 `false`。设置中的更新入口打开下载页面，不在自签名构建内下载安装维护者签名的更新包。原有 APK 摘要、包名、版本与签名校验实现保留；维护者自行接入同签名更新服务时须一并核对 URL 策略和签名身份。

## 公共数据与缺失数据处理

公开版本的基础地铁目录由附带的 OSM 图层生成，具体范围、来源、拆分和许可见 [DATA_SOURCES.md](DATA_SOURCES.md)。它不附带开发工作区里的运营方图片、官方图像素热区、精确描摹线图或高德地铁数据库快照。

- 数据文件可声明 `crs: WGS84`；加载时明确转换为业务模型需要的坐标，不把两种坐标系混用。
- 线路保留 `networkId`、`serviceLabel` 和 `dataSource`。存在断口或分岔的 OSM 拓扑分段不会伪装成官方列车交路。
- 没有首末班时刻时字段保持未知，不能自动补成 06:00—23:00；不生成预测列车或到站班次，不把“无时刻表”写成“已收班”。
- 区域铁路的公共站序采用程序生成的原创拓扑示意点位，保留点站选起终点的交互。它不代表真实地理位置，不是官方图。运营方图片及金山铁路图片入口转为打开外部官方页面。
- `PublicBuildConfig.ALLOW_UNDOCUMENTED_METRO_FETCH` 默认为 `false`，公共构建不会因缺少地铁数据库而自动从未文档化接口补抓一份。用户配置自己的高德 Web 服务 Key 后，仍可使用文档化查询路径；服务权限、配额和数据使用条件另行适用。

## 运行时依赖

实时公交、在线地图、港铁及港澳巴士预计到站、城际班次查询和高德规划仍需要对应的外部服务。源码公开不能保证服务一直可用，也不能替代第三方的许可。网络请求中的实际位置属于运行时行为，应结合首次启动和 Key 使用说明审查，不能把删除仓库内日志当成完整隐私保护。

## 验证边界

公开准备包含静态凭据检查、可构建性和既有模型回归；新增断言覆盖无时刻表不生成列车、自签名公版不启用正式签名更新，以及未文档化地铁抓取默认关闭。最后发布所用构建日志由维护者记录。

没有在本报告中展示凭据值，也没有把“未发现凭据”当成全历史、所有依赖和所有服务器都安全的证明。仍需保留第三方来源、发布前检查最终 Git 暂存区，并检查新克隆目录能否重建。
